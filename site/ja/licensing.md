# ライセンス

Simpludify本体、サンプルコード、同梱SVG・プレースホルダーの原著部分はMITです。商用ゲームでも利用できます。ゲーム自身のオリジナルコードやアセットをMITにする義務はありません。

## 配布に含めるもの

ビルドは`LICENSE.txt`、`THIRD-PARTY-NOTICES.txt`、`sbom.json`を生成します。サイトでもゲームでも、配信出力全体とともに保持してください。依存ライブラリのライセンスはそれぞれ有効です。

画像・フォント・音声等を自分で追加する場合は、利用・改変・再配布・帰属表示の条件を別途確認します。公式サイトは外部フォント・アクセス解析・CDNスクリプトを読み込みません。サンプルはリポジトリ内のアセットを使用します。

## 依存関係とツール

`npm run check`はlockfileのライセンス宣言とインストール済みnoticeを検査します。未承認のライセンスは失敗にします。公式サイトが追加する直接依存はビルド用のmarkdown-itだけで、エンジンの実行時依存は増やしていません。

依存一覧は独自形式であり、SPDX/CycloneDX認証やバイナリ全体の法的監査ではありません。他OS用のoptional binaryはlockfileに含まれていても、配布先のインストール環境でnoticeを再確認する必要があります。
