# サンプルギャラリー

コードを読む前に、ブラウザで動作を試せます。起動するまでゲームをロードしません。同時に動かすサンプルは1つで、別のサンプルを選ぶか「終了する」で前のGameを破棄します。

WebGLの描画経路を中心に検証しています。固定したPixi版には代替描画の自動選択があり、WebGL無効時のCharacterのCanvas2D起動も限定的に確認します。全サンプル・全機能の代替描画互換性を保証するものではありません。小さな画面ではサンプル欄までスクロールしてください。広いゲーム領域が必要なら別タブで開けます。Signal Run・Blockfall・Prism Raidはタッチだけでゲームを操作できます。その他のキャラクター移動にはキーボードが必要です。

## 学習の順番

1. Character：Game・Character・型付きActionの最小構成。
2. UI / Scenes：型付きScene ID、DOM UI、非同期遷移。
3. Beacon Field：独自Component、イベント、タイマー、ポインター座標、生成・削除。
4. Signal Run：Triggerで取得・被弾、Solidで壁沿いの移動、HP・制限時間・勝敗・ポーズ・再プレイ・カメラ追従。

5. [Blockfall](../../examples/blockfall/README.md)：整数グリッド、seed付き7-bag、回転・壁蹴り、行消去・得点、ホールド・ゴースト、キーボード・タッチ、ヘッドレス再現テスト。

6. [Prism Raid](../../examples/prism-raid/README.md)：Triangle、移動と連射、複数の敵、Trigger、無敵時間、3ウェーブ、通常入力による自動プレイヤー。

## フォーカスと終了

iframeはページ本体と別の文書です。ゲーム内のキー操作はゲームをフォーカスしている間だけ有効です。Tabでゲームやボタンへ入り、Tabでページへ戻れます。終了ボタンで起動元へフォーカスを戻します。タブを非表示にするとWeb入力が解放されます。

サンプル変更時は明示的にGame.disposeを実行してからiframeを取り除きます。直接開いたサンプルもpagehideで片付けます。履歴の復元で破棄済み文書へ戻った場合は再読み込みします。これは汎用の安全な外部コード実行環境ではなく、このリポジトリの信頼されたサンプルを分離する構成です。

## 動作範囲

公開APIで構築した既存例を使用しています。検証対象はChromiumのデスクトップ・幅390pxレイアウトと合成タッチ入力です。実機Safariや全GPUでの検証ではありません。起動に失敗した場合の案内と、[現在の制約](limitations.md)を確認してください。
