# Canvasスクロールとジェスチャー所有権

`CanvasScroll`は、独立した位置、入力ポリシー、慣性、オーバーレイスクロールバーを備えたCore UIパネルです。Webはネイティブなポインターキャプチャ／座標変換とPixi描画を供給します。コンテンツ定義にDOMやPixiの操作は不要です。

```ts verify
import {
  CanvasButton,
  CanvasColumn,
  CanvasLabel,
  CanvasScroll,
  Game,
} from "@simpludify/web";
const inventory = CanvasScroll(
  Array.from({ length: 40 }, (_, i) =>
    CanvasButton(`Item ${i + 1}`, () => {}, { height: 44 }),
  ),
  {
    height: 240,
    scroll: "vertical",
    dragScroll: true,
    inertia: true,
    scrollbar: "auto",
  },
);
const notes = CanvasScroll(
  [CanvasLabel("A separate viewport", { height: 400 })],
  {
    height: 120,
    inertia: false,
    scrollbar: "always",
  },
);
const game = new Game();
const ui = game.canvasUI(
  CanvasColumn([inventory, notes], { gap: 12, padding: 12 }),
);
await game.run();
inventory.setStyle({ inertia: false, scrollbar: "hidden" });
inventory.scrollTo(0, 80);
console.log(ui.diagnostics.activeMomentum);
```

## 設定と単位

| 設定          | 既定値                   | 意味                                                                                                     |
| ------------- | ------------------------ | -------------------------------------------------------------------------------------------------------- |
| scroll        | vertical in CanvasScroll | vertical, horizontal, または both。子孫をクリップし主軸のオーバーフローを保持                            |
| dragScroll    | true                     | マウス／ペン／タッチによるコンテンツドラッグを許可。スクロールバー操作は無効化しない                     |
| inertia       | true                     | コンテンツドラッグ後の慣性を許可。無効化すると実行中の慣性は直ちに停止                                   |
| scrollbar     | auto                     | auto: あふれた場合のみ表示, always: 常にトラックを確保, hidden: 描画・ヒットなし（スクロール自体は有効） |
| dragThreshold | 8                        | ホストスクリーン単位の有限・非負の閾値。UI scaleやDPRとは独立して評価                                    |

スクロールパネルには有界なサイズまたはFlex growの割り当てを指定してください。位置と範囲はUI単位です。ポインター位置と閾値はホストスクリーン単位です。アダプターはスクリーン座標をUI scaleを通じて変換します。ワールドCameraや物理DPRがスクロール計算に入ることはありません。スタイルは各ノードに属し、コンテナ間で共有されるグローバルな既定値ではありません。`setStyle`はパッチ全体を検証してから適用します。

`scrollTo(x,y)` / `scrollBy(dx,dy)`は、最後に解決された`maxScrollX/Y`に対してクランプします。これらは慣性を停止し、そのスクローラーのアクティブなポインター制御および保留中の子孫ノードの押下をキャンセルします（no-opコマンドを含む）。`stopScroll()`は慣性のみを停止します。`coasting`は速度が残っているかどうかを公開します。構造やサイズの変更は次回のレイアウト時に範囲を再計算し、オフセットをクランプします。軸やポリシーの変更は無効になったジェスチャー所有権を直ちにキャンセルします。UI scaleを変更すると、古いジェスチャーサンプルが異なる単位スケールを適用しないよう、UIジェスチャーと慣性がキャンセルされます。

## ジェスチャー調停ルール

- Downはまず最前面のUIまたはワールドターゲットを選択します。UIスクロール候補はそのノードの祖先パスのみです。後から追加されたオーバーレイやワールドジェスチャーが、背後にあるスクロールパネルに奪われることはありません。
- サポートされた軸の閾値（dragThreshold）に達するまで、既存のターゲットが通常の入力を所有します。ボタンのタップや閾値未満の移動は通常の決定動作を維持します。`CanvasHoldButton`は既存の**即時長押し状態**契約を維持し、遅延ロングプレス認識ではありません。
- スクロールジェスチャーが勝つと、元のポインター寄与が解放され、ターゲットは1回の`PointerCancel`を受信します。ネイティブのキャプチャは維持されます。選択されたスクローラーは新しい`PointerDown`を受信し、後続のMove/Up/Cancelを所有します。キャンセルされたターゲットにはClickやUpによる発火は届きません。
- ジェスチャー開始時に最も深い可動祖先が勝ちます。端点に達した子は可動な親へ委任できます。異なる向きの祖先は自身が動かせる軸のみを考慮します。**所有権は解放までロックされたままです。**ドラッグ中に端点に達しても親へ自動で跳び移ることはありません。所有者を変更するには一度解放して新しいジェスチャーを開始してください。
- 1つのポインターが同時に1つのスクローラーを制御します。別のポインターがそのコンテンツやつまみを奪うことはできません。別々のスクローラーは同時に操作可能です。
- 無効化、非表示、除去、方向やドラッグポリシーの変更、プログラムコマンド、UI/Scene差し替え、blur、pointercancel、キャプチャ喪失によって関連状態が解放されます。キャンセルされたIDは物理的な解放または新しいDownまで抑制されたままになります。

第1ボタン（左クリック／タッチ／ペン）のコンテンツ／つまみ入力のみがスクロールします。PointerInfoは任意の`time`（単調増加ホスト秒数）を保持します。timeを省略した既存アダプターでもドラッグは可能ですが、慣性を開始することはできません。

## 慣性とクロック

直近の入力速度は45msの指数フィルタを使用します。150ms以上離れたサンプル、欠損・非有限・非単調なタイムスタンプ、最後のmoveから80ms以上経過した解放は慣性を開始しません。速度は軸ごとに3000 UI単位/秒に上限が設定されます。解放後は8/秒の指数減衰を使用し、10単位/秒で停止します。各軸は自身のスクロール境界で停止し、バウンス（跳ね返り）はありません。

Coreは`ui.advance(seconds)`を公開し、動いているノードのみを含むSetを保持します。RAF、ホストタイマー、隠れた購読は持ちません。無効な時間や負の時間は位置を変更せずにスローします。250msを超える不連続性は大きなジャンプを適用せずに慣性を停止します。`ui.stopMotion()`はそのツリーのすべての惰性移動を終了します。

Web Gameは既存のフレームチェーンを通じてプレゼンテーション経過秒数を渡します。Gameの一時停止、blur、非表示、Scene破棄は慣性を停止し、再開しても復活しません。

## オーバーレイバーとキーボード操作

スクロールバーはViewport上にオーバーレイされ、レイアウト空間を占有せず、既存のテキスト色を使用します。可視トラックは幅8 UI単位で2単位のインセットを持ちます。つまみの長さは`viewport / (viewport + range)`を反映し、トラック長で制限された最小24単位を持ちます。交差軸のヒット領域は少なくとも24ホスト単位であり、祖先のクリップを尊重します。

無効化されたコンテナは薄暗いバー幾何形状を保持しますがバー入力を受け付けません。非表示や破棄されたツリーはバーを描画しません。オーバーフローのない`always`は薄暗いフルトラックのつまみを表示し、ポインターヒットを消費しますが移動はしません。つまみの直接ドラッグは現在の範囲／トラックに直接マッピングされます。トラック押下はViewport範囲の90%ページ送りします。これらの操作は慣性を開始しません。

Tab/Shift-Tabはフォーカスされたコンテンツを表示位置までスクロール（reveal）させます。フォーカスされたCanvasコントロール上での矢印キー、PageUp/PageDown、Home、Endは、直近の可動祖先をスクロールします。

## レイアウトと描画コスト

オフセットの変更はFlexではなく**投影（projection）**を無効化します。スクロールされていない凍結レイアウトボックスは弱く保持され、フラッシュはテキストの再計測やサイズの再解決を行うことなく、現在の祖先オフセットから新しい境界を投影します。構造、テキスト、フォント、サイズ、スケールの変更は依然として完全なレイアウトを実行します。

レンダラーは描画／スタイルおよびマスク署名を平行移動とは個別にキャッシュします。コンテンツが動いても背景幾何形状やTextStyleは再構築されず、変更のないクリップはマスクを再構築しません。

## サンプルと検証

Canvas trail → **UI list lab**に、ライブの慣性／ドラッグ／バー切り替え、独立して設定された第2のViewport、入れ子の両軸カード、HoldButtonが含まれています。画面定義はCoreのみをインポートし、ヘッドレステストと共有されています。
