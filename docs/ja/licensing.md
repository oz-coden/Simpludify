# ライセンスと依存関係

Simpludifyのオリジナルエンジンソース、サンプルコード、同梱されたSVG／プレースホルダーデザインにはルートのMITライセンスが適用されます。商用ゲーム、改変、再配布もそのライセンスに基づいて許可されます。このエンジンを使用することによって、ゲーム独自のコードやアセットにMITライセンスの適用が強制されることはありません。依存パッケージや独自に取得したコンテンツは、それぞれの利用条件に従います。

## レビュー済みの依存関係

バージョンはワークスペースのマニフェストとnpm lockfileで厳密に固定されています。初期レビューでは、2026-10-26時点でnpmメタデータとインストール済みライセンスファイルを検査しました。

## 自動通知とインベントリ

`npm run check`は、lockfile内のすべてのパッケージライセンス宣言をレビュー済みの許可リストと照合し、インストールされたパッケージのライセンス／noticeファイルの存在を検証します。未レビューの新しいライセンス識別子は検査で失敗します。他プラットフォーム向けのオプションバイナリは、現在のホストにインストールされていなくてもインベントリに記録されます。これらのバイナリを再配布する際は、パッケージングを行うホスト上で上流ファイルを再確認する必要があります。

`npm run build -- --target web`は以下を生成します。

- `dist/LICENSE.txt`: オリジナルのエンジン／サンプルのMIT通知
- `dist/THIRD-PARTY-NOTICES.txt`: ビルドツールを保守的に含む、インストール済み依存関係のライセンス／notice本文
- `dist/sbom.json`: バージョン、整合性ハッシュ、ライセンス、dev/installedフラグを含む、バージョン管理されたJSON依存インベントリ

このインベントリはプロジェクト固有のSBOMスキーマ（`simpludify-dependencies-v1`）であり、SPDX/CycloneDXの認証やバイナリレベルのコンプライアンス監査ではありません。Vite/Rolldownによってパッケージ化された第三者通知も保持されます。

一部のオプションツールバイナリには個別のライセンスファイルが含まれていません。ジェネレータは、それらを所有するBiome/Rolldown配布物のnoticeを含めます。`@pixi/colord@2.9.6`には上流のライセンスファイルが含まれていませんが、[third-party/colord](../../third-party/colord/LICENSE.md)に上流のMIT本文を保持しています（[ライセンスコミット](https://github.com/omgovich/colord/blob/0d16e3b7ab0a4bcb42e6682712cc124af5f7ce9d/LICENSE.md)より取得）。依存関係を更新する際にこのフォールバックを再評価してください。

ViteのオプションであるLightning CSSツールは、lockfile内にMPL-2.0として現れます。チェッカーはMPLを開発時依存としてのみ許可しており、ゲーム実行時の承認済み依存ではありません。現在のビルドはLightning CSSを有効化しておらず、そのバイナリも同梱していません。そのツールを再配布したり、コードを改変・バンドルする場合は、ソースコード公開義務について個別のレビューが必要です。[MozillaのMPL FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/)を参照してください。

## 配布チェックリスト

配布するゲームには、エンジンのMIT通知と生成されたサードパーティnoticeを同梱してください。新しく追加した画像、フォント、音楽、コードについては、帰属表示や再配布権を含めて個別に確認してください。依存関係を変更した後は、検査とインベントリ生成を再実行してください。デスクトップパッケージングを行う場合は、Electron/Chromium/Nodeおよび同梱されるすべてのネイティブバイナリのレビューが追加で必要になります。互換性のあるソースライセンスであっても、任意に提供されたコンテンツの権利関係や一般的な安全性を保証するものではありません。

## 公式サイトのツール

公式サイトは、厳密な開発依存関係としてmarkdown-it 15.0.3（MIT）を追加しています。argparse、entities、linkify-it、mdurl、punycode.js、uc.microを含む7つのロックされた追加パッケージは、2026-10-27時点で検査されました。argparse 3.0.4はPSF-2.0を宣言しており、Python Software Foundationライセンス本文を含みます。完全なファイルはnoticeジェネレータによって保持されます。PSF-2.0は開発時依存としてのみ許可されています。Markdownパーサーがゲーム実行時コードとして同梱されることはありません。生成されたサイトには、単一ゲームの出力と同様に、保守的なビルド／実行時の結合インベントリとnoticeが含まれます。サイトはシステムフォント、自前のCSS/JS、既存のMITサンプルアセットを使用し、外部フォントやアクセス解析、CDNランタイムは追加されません。
