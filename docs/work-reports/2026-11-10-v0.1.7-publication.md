# v0.1.7 publication and Run To Exit adoption

## Release source

The immutable `v0.1.7` tag points to Simpludify main commit `2ee6eb416687ed61014e640db0aa90635a8b92ed`. [Main push CI](https://github.com/oz-coden/Simpludify/actions/runs/42713238007) passed all 20 jobs, including 18 validation jobs, Pages deployment and the six scripts exercising the deployed revision. Candidate coverage included 892 unit tests, 462 engine browser tests, Windows and Linux package and starter checks, and the pinned Run To Exit consumer with 35 unit tests and 66 E2E cases in WebGL and Canvas2D.

The [approved tag workflow](https://github.com/oz-coden/Simpludify/actions/runs/42714828595) validated the source SHA against the successful main push. The registry returned 404 for both exact package versions before publication, and there was no existing GitHub Release for the tag. The [publication workflow](https://github.com/oz-coden/Simpludify/actions/runs/42714997409) uses Trusted Publishing, verifies the hashes of the archives from the validation job and checks Core's public integrity before publishing Web.

## Release scope

Applications must replace `game.goTo(id)` with `game.changeScene(id)`. Scene transition order, cleanup after failed preparation or presentation, tilemap layer reconciliation and image ownership, gamepad binding normalization, and Canvas input on collapsed hosts were reviewed and verified. The [independent review](2026-11-10-v0.1.7-independent-review.md) records the regression cases and the limits of the browser coverage.

- [Core 0.1.7](https://www.npmjs.com/package/@simpludify/core/v/0.1.7) was accepted at 07:49:01 JST and verified against the registry integrity at 07:53:10 JST. The [Core provenance](https://search.sigstore.dev/?logIndex=3771875298) points to `npm-publish.yml` and the tagged commit.
- [Web 0.1.7](https://www.npmjs.com/package/@simpludify/web/v/0.1.7) was accepted at 07:53:26 JST and verified against the registry integrity at 07:54:24 JST. The [Web provenance](https://search.sigstore.dev/?logIndex=3771972413) points to the same source and workflow.
- The [registry acceptance job](https://github.com/oz-coden/Simpludify/actions/runs/42714997409/job/129497477438) passed both clean-install commands. Coverage includes Core-only Node and NodeNext use, Web-only transitive Core resolution, strict external declarations, Vite production subpath and browser checks, and a fresh starter with scene restart and license notices.
- The [GitHub Release](https://github.com/oz-coden/Simpludify/releases/tag/v0.1.7) uses the existing tag and documents the breaking method rename, quality improvements and installation.

## Run To Exit adoption

The [pre-adoption main CI](https://github.com/oz-coden/Run-To-Exit/actions/runs/42713031717) stopped during type checking in all six jobs because the source already used `changeScene` while the lockfile still installed SDK 0.1.3. The [adoption commit](https://github.com/oz-coden/Run-To-Exit/commit/62425811993eb215129c98db33b9c8ae7cdd5be5) updates both dependencies to exact public npm v0.1.7 and updates the E2E inventory expectation. The lockfile resolves a single Core and records the same archive integrities as the public registry. `npm ci`, type checking, 35 unit tests, the production build and all 66 browser tests across six configurations passed locally with Playwright retries disabled.

[Run To Exit main CI](https://github.com/oz-coden/Run-To-Exit/actions/runs/42716181488) passed all six WebGL and Canvas2D configurations without a test retry and [deployed to Pages](https://github.com/oz-coden/Run-To-Exit/actions/runs/42716181488/job/129500462956). The [deployed game](https://github.oz-coden.com/Run-To-Exit/) serves both SDK packages at 0.1.7 with the registry integrities. Its HTML, Vite manifest, game entry, main JavaScript and stylesheet matched the local production build byte for byte. A browser playthrough on the public URL loaded and played the built-in solution and confirmed that both characters escaped in nine steps. The live playthrough used the browser's default renderer. The full renderer and viewport matrix ran on the same production build in CI and locally.

## Remaining limits

The earlier intermittent desktop Canvas2D camera observation described in the [CI review](2026-11-09-ci-sdk-candidates.md#main-results) remains open and did not recur in the release CI. The Chromium matrix covers software rendering and emulated viewports. The checked-in starter template retains its published v0.1.6 pins, and the 0.1.7 acceptance job verifies a fresh copy using the new public packages. This publication record and the changelog cleanup are saved as a documentation-only main commit. The tag identifies the exact source validated and published by the release workflows.
