## Public-registry consumer verification

`npm run test:packages:registry` succeeded in the publish job using standard Chromium 156. It created genuine empty temporary projects, installed public npm packages without workspace links, and verified:

- Core-only Node import/lifecycle, matching `ENGINE_VERSION`, and strict NodeNext declarations without DOM ambient types.
- Web-only installation with the exact transitive Core dependency, physical external dependencies and a successful fresh `npm ci`.
- Strict Web public declarations without workspace aliases or `skipLibCheck`, and the explicit CSS export.
- A Vite production build under `/external-game/`, bundled scoped CSS and an application image.
- Development and production browser operation at widths 1280, 390 and 320: visible rendering, keyboard movement, Canvas pointer/keyboard controls, Scene replacement and idempotent resource cleanup.

An independent empty local project explicitly installed both registry packages, repeated `npm ci`, and installed exact TypeScript 7.0.2 / Vite 8.3.5 tooling. `npm audit signatures` verified registry signatures for all 31 installed packages and attestations for 13 packages. A strict TypeScript check and production `/registry-check/` game build passed. Core's Node program verified ActionController, ActionSource writes, a stable ActionReader, button press/release boundaries, disable/re-enable without restored holds and disposal.

The additional browser consumer verified exported `GamepadInput`, `GamepadSource`, `GamepadBindings`, `GamepadButton`, `GamepadAxis`, `gamepadButtonLabel` and public Gamepad types. A structural mock provider exercised neutral arming, analog movement, button edges, disable/release and adapter cleanup. A real Game used `Game.gamepads` and a program-driven Character; movement, source-disable stop and double-dispose cleanup passed at all three widths with no uncaught page errors. This is mocked-device verification, not physical gamepad certification.

Local `npm run test:packages:registry` also passed all six consumer check groups using supplemental Chromium 153.0.8010.0. Standard Chromium downloads were truncated on this work host; standard Chromium verification remains the successful GitHub job above. The supplemental browser's archive extractor first failed on host `chown`; manual extraction with preserved contents resolved setup. An initial extra fixture needed an explicit mutable boolean type, and an initial supplemental launch with serverless-specific arguments closed before page creation; correcting the fixture type and using the existing consumer's standard launch flags produced the passes recorded here. These setup/fixture failures were not counted as passes and changed no SDK code, product assertion or timeout.

## Limits and safe resumption

Physical gamepads, vendor labels/drivers, vibration, physical mobile keyboards, actual OS IME, screen readers, Safari and Firefox remain unverified. Emulated viewports and structural pad providers do not establish physical-device or non-Chromium support. Experimental 0.x APIs may change.

Both package results are `published-verified`; neither package needs publication again. Before any interrupted continuation, read the current tag, npm manifests, publication JSON, GitHub Release and main CI. Preserve existing versions and the tag. Remaining work, if the final main run has not yet finished, is limited to checking that run and adding its result to the Release verification notes. Independent consumer upgrades are outside this publication record.
