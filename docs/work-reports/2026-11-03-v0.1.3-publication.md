## Release changes

Canvas labels mirror readable text and optionally heading levels or stable atomic status/alert regions. Text inputs accept a portable numeric/decimal keyboard hint without changing raw validation semantics. Explicit focus resolves changed geometry, repeat focus reveals moved controls, and disposal ignores invalidation while releasing routing ownership. Web culls fully clipped paint and caches visible scroll screens internally; pooled targets return intact to Pixi and renderer disposal frees managed GPU data. Core remains host independent. No application UI framework or new renderer configuration is required.

Detailed design, failed candidates and regression evidence are in [Canvas consumer integration](2026-11-02-canvas-consumer-ui.md). In particular, the withdrawn explicit GPU unload caused blank pooled-cache paint; repeated actual-pixel tests detect it. Earlier semantic-only operation passes are not visual validation of that faulty candidate.
