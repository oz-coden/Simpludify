## Independent findings and fixes

| Area                                    | Review result and coverage                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Scene queue                             | A single tail marker correctly coalesces adjacent identical requests while retaining each intervening target. Clearing the marker at activation permits a synchronous hook to enqueue a new navigation with an independent Promise. The regressions verify active A to B to A, B to C to B, setup failure during a mixed queue, settlement and cleanup order, fresh Scene instances, aborted signals and final input ownership. The existing pending-disposal and committed-lifecycle-error cases remain.                                                              |
| Scene failures                          | A factory that disposes its Game before returning a rejected Promise could leave that Promise unobserved. A first-render failure after activation could leave a committed but disposed Scene until the next host frame. The Game now observes the setup rejection and disposes the host immediately on a committed presentation failure. The original navigation error is preserved, queued calls reject with `GAME_DISPOSED`, and the replaced presentation is cleaned up even if installation throws.                                                                |
| Tilemap reconciliation                  | Separate visual maps correctly track the two layer types, but the existing count assertion passed even when the sprite sheet lease was discarded. The lease check used the map's internal placement instead of the Actor carrying its layer. Reconciliation now checks that Actor, skips disposed maps, and applies Actor and layer enable flags to both visual types. Pixel tests cover equal and changed depth, disable and enable, same-map reuse, two replacements in one frame, both map types, removal and re-addition, and lease release in WebGL and Canvas2D. |
| Gamepad bindings                        | The last entry for a physical button wins within one Action, including a threshold change via `addBindings`. Different Actions or binding paths still report a conflict. Tests cover physical-index removal, cross-Action conflict, and validation of every input before deduplication so an invalid threshold cannot be hidden by a later entry. An explicit null threshold now fails validation.                                                                                                                                                                     |
| Canvas input                            | The native wheel zero-rect guard is correct, but the corresponding test described in the initial report was absent from the diff. Host-level wheel and captured pointer events could still attempt projection on a collapsed rectangle. Both wheel routes now ignore the collapsed host and pointer release clears the held state. The new browser test checks real DOM dispatch, zero capture after release, no wheel consumption and no error in both renderers.                                                                                                     |
| Scene registration and tile coordinates | Invalid Scene names and factory values fail at registration, as tested by the original review. The signed-zero Tilemap normalization preserves out-of-bounds behavior for finite inputs. The original unit regression checks both axes with `Object.is`.                                                                                                                                                                                                                                                                                                               |
| Released starter and registry           | The renamed method is exposed by candidate Web only. The distributed starter retains the restart call matching its published v0.1.6 lock. Candidate or newer registry validation updates the isolated starter copy to `changeScene`. The package fixture likewise selects the published call only for the isolated v0.1.6 registry check. There is no compatibility alias in the SDK.                                                                                                                                                                                  |

Activation hooks run synchronously. After startup they can enqueue navigation and handle its Promise separately. Navigation requested from inside an asynchronous factory starts after that factory's own transaction settles.
